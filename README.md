## 🌟 Особенности

- **Умный ИИ** с анализом контекста и эмоций
- **Общая память** - запоминает всё, что говорят пользователи
- **Мини-игры** (крестики-нолики, математика, память, викторина)
- **Админ-панель** с просмотром всех пользователей и переписок
- **Секретные знания** о пользователях (Демид + Настя = ❤️)
- **Настраиваемый профиль** с выбором цвета аватара
- **Локальное хранение** данных в браузере
- **Полностью на русском языке**

## 🚀 Быстрый старт

### Вариант 1: Открыть онлайн
Просто откройте [index.html](index.html) в браузере!

### Вариант 2: Локальная установка
```bash
# Клонировать репозиторий
git clone https://github.com/ваш-username/ai-assistant.git

# Перейти в папку проекта
cd ai-assistant

# Открыть в браузере
open index.html  # Mac
start index.html # Windows
xdg-open index.html # Linux
