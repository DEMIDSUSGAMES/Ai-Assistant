# AI Assistant 🤖

Умный искусственный интеллект который всё понимает и запоминает.

## 🚀 Быстрый старт

1. **Скачай все 4 файла** в одну папку:
   - `index.html`
   - `style.css`
   - `ai.js`
   - `app.js`

2. **Открой `index.html`** в браузере

3. **Введи своё имя** и нажми "Начать"

## 🌟 Особенности

✅ **Умный ИИ** - понимает контекст и эмоции  
✅ **Запоминает всё** - сохраняет все разговоры  
✅ **Знает секреты** - Демид + Настя = ❤️  
✅ **Админ-панель** - `/admin admin123`  
✅ **Изменение имени и цвета**  
✅ **Работает на телефоне и компьютере**  
✅ **Не требует интернета** после загрузки

## 🎮 Как пользоваться

### Чат с ИИ:
- Напиши любое сообщение
- ИИ ответит умно и по контексту
- Используй знаки вопроса и восклицания

### Секретные команды:
- `/admin admin123` - доступ к админ-панели
- "Кто такой [имя]" - узнать о пользователе
- "Запомни [факт]" - научить ИИ чему-то новому

### Меню ИИ (нажми на аватар 🤖 в чате):
- **Очистить чат** - удалить историю
- **Что я помню** - показать память о тебе
- **Научить ИИ** - добавить новый факт

## 📊 Что запоминает ИИ

1. **Все сообщения** в чате
2. **Имена пользователей**
3. **Факты** которым его учат
4. **Цвета аватаров**
5. **Время последнего входа**

## 🚨 Если что-то не работает

1. **Обнови страницу** (F5)
2. **Проверь консоль** (F12 → Console)
3. **Очисти кэш браузера**
4. **Убедись что все 4 файла в одной папке**
